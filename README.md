# Java Set Practice 

A basic Java exercise practicing the usage of the `Set` interface (`HashSet`) to handle unique data and eliminate duplicates.

---

##  Exercise Description

In an online course portal, each user has a unique ID represented by an integer. 

Each instructor can have multiple courses, and a student can enroll in as many courses as they want. Therefore, the total number of unique students for a specific instructor is not simply the sum of all students in their courses, since there might be duplicate enrollments.

The instructor **Alex** has three courses: **A, B, and C**. The goal of this program is to read the students for each course, filter out duplicates, and display the total number of unique students.

### Example:
```
How many students for course A? 3
21
35
22
How many students for course B? 2
21

How many students for course C? 3
